# Finanz India — Investment Module Prototype

Clickable demo of the Finanz India investment module. Runs entirely in the
browser on synthetic sample data: no backend, no live connection, no real
lenders, brokers or bureau data. Descriptive-only by design; the two amber
"concept" screens are internal evaluation mockups and say so on-screen.

Built from the finanz-india-starter workspace. Deployed as a single
self-contained HTML file via GitHub Pages.
